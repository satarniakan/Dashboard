# نقشه راه: فروشگاه اینترنتی روی پلتفرم Dashboard

زیرساخت موجود: کالا با عکس/واحد/گروه/Variant، انبار و موجودی، مشتری، فاکتور فروش، قسط، خزانه و حسابداری.
آنچه ساخته می‌شود: لایه‌ی عمومی (ویترین)، سبد خرید، کد تخفیف، درگاه پرداخت و چرخه‌ی سفارش.

## معماری پایه
- فروشگاه به‌صورت ناحیه‌ی عمومی داخل `Dashboard.Web` (نه پروژه‌ی جدا)، زیر `/shop`.
- صفحات ویترین: **Static SSR** (بدون `@rendermode`) برای SEO و هزینه‌ی سرور نزدیک صفر؛ فقط سبد خرید/پرداخت Interactive.
- Layout مستقل فروشگاه (`StoreLayout`) با هویت بصری خودش؛ متغیرهای تم (`--brand-*`) مشترک.
- منبع حقیقت موجودی = انبار؛ فروش آنلاین از انبار مشخص (مثلاً «انبار فروش آنلاین») کم می‌کند.
- سفارش با انتیتی مستقل `Order` مدیریت می‌شود؛ پس از پرداخت موفق، `SalesInvoice` + سند حسابداری خودکار ساخته می‌شود.
